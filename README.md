## Plugins on this profile

Counter-Strike 2 plugins in C# on CounterStrikeSharp, plus a few older SourceMod ones.

| Plugin | What it does |
| --- | --- |
| **[GangSystem](https://github.com/MRxMAG1C/GangSystem)** | Gangs for jailbreak servers: roles, credits, missions, upgrades and broadcasts. |
| **[RoundEndGravity](https://github.com/MRxMAG1C/RoundEndGravity)** | Low gravity when the round ends, normal again when the next one starts. |
| **[LimitTeamChange](https://github.com/MRxMAG1C/LimitTeamChange)** | Caps how many times a player can switch teams in a round. |
| **[HelpCommand](https://github.com/MRxMAG1C/HelpCommand)** | Lists the server commands a player can use, in a chat menu. |
| **[UserConfigSaver](https://github.com/MRxMAG1C/UserConfigSaver)** | Saves each player's CS2 config to MySQL when they connect. |
| **[Admintag](https://github.com/MRxMAG1C/Admintag)** | Adds or removes the [ADMIN] clan tag from the player's admin group. SourceMod. |
| **[Commands](https://github.com/MRxMAG1C/Commands)** | The SourceMod commands a player can use, in a menu. |

## What I build with

C# and CounterStrikeSharp for servers. TypeScript, Svelte and plain JavaScript for the web, with WebRTC when two devices should talk directly. Chrome extensions on Manifest V3. Cloudflare Workers, Durable Objects and D1, Supabase and MySQL behind them. Electron for the desktop.
